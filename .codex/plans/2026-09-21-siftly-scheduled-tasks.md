# Siftly定期インポート・AI分類 計画

> 履歴資料。現在の完了/未完了と着手順は[2026-09-26作業台帳](2026-09-26-siftly-work-ledger.md)を参照。この文書にある相対`StartInterval`・睡眠時の説明・モデル名は当時の案で、現行の確定事項ではない。

## 目的

- X OAuthのライブインポートを3日ごとに実行する。
- 未処理ブックマークのAI分類を7日ごとに実行する。
- 各処理の成功・失敗結果をDiscord Webhookへ送る。

## 実施内容

1. 既存の `/api/import/x-oauth/fetch` と `/api/categorize` を呼び出す用途別ラッパーを追加する。
2. macOSのLaunchAgentを2つ登録する。初回起動時には実行せず、3日後・7日後から実行する。
3. OpenAI OAuthと `gpt-5.6-luna` はSiftlyの既存設定をそのまま使う。
4. X APIの月間上限エラーはDiscordへ通知し、上限回復後の次回実行で自動再試行する。
5. macOSのLaunchAgentではCodex CLIの実体パスを明示し、OAuth実行経路を安定させる。

## 検証

- シェル構文検査。
- plistの構文検査と `launchctl print` による実行形式確認。
- ネットワークへ書き込まないドライラン。
- X API上限が回復するまでは実際のインポートを手動実行しない。

## リスク

- Macが停止・ログアウト中の実行は遅延する。
- X API上限中はインポートが失敗するが、スケジュールは停止しない。
- AI処理はSiftly内のOpenAI OAuth設定とCodex CLIに依存する。
