# Siftly外部リンクプレビュー実装セッション保存計画

作成日: 2026-08-16
目的: 今回のSiftly外部リンクプレビュー実装と検証結果をObsidian知識ベースへ保存する。

## 手順

1. `03_知識ベース` の既存分類を確認する。
2. 実装内容、実機確認、テスト結果、未確認事項を日本語で整理する。
3. `AI知見` に新規ノートとして保存する。
4. 保存後にファイルの存在と内容を確認する。

## 保存方針

- APIキー、OAuthトークン、Cookie、個人情報は記録しない。
- 実ページそのものではなく、安全なローカルプレビュー画像を生成する仕様であることを明記する。
- Obsidianアーカイブへの画像埋め込みは、既存の直接接続経路がなかったため今回の対象外として記録する。
